## Глоссарий терминов проекта

| Термин | Определение |
|--------|-------------|
| DataMatrix-код | Двумерный матричный код, используемый для маркировки шин в системе «Честный знак» |
| «Честный знак» | Внешняя система маркировки товаров; источник атрибутов кодов (brand, model, size, product_name) |
| Номенклатура | Уникальное сочетание brand + model + size; справочная сущность |
| TireCode | Конкретный DataMatrix-код, привязанный к номенклатуре, складу и (опционально) документу |
| Площадка | Самостоятельная сущность (например, «Софийская Груз»); содержит склады и пользователей |
| Склад | Единица учёта внутри площадки; типы: основной (main) и ответственное хранение (oh) |
| Поставщик | Поставщик для складов ответственного хранения |
| Документ | Документ списания (writeoff) или выкупа (buyout) DataMatrix-кодов |
| Строка документа | Номенклатура + количество; дубликаты номенклатуры запрещены |
| FIFO | Выбор кодов по дате загрузки в систему (внутри дня — по ID) |
| Проведение | Атомарная транзакция: проверка остатка → FIFO-выбор → пометка кодов → счётчики → смена статуса |
| Распроведение | Откат проведения: возврат кодов в активные, восстановление счётчиков |
| Экранное отображение | Показ закреплённых за документом кодов; доступно только после проведения |
| Счётчики активных кодов | Количество неиспользованных кодов по позициям и складам |

## Связи между артефактами

```
Артефакт 0 (Исходные требования)
  │
  ├──→ Артефакт 1 (User Stories)
  │      │
  │      ├──→ Артефакт 2 (Тест-кейсы)
  │      │
  │      └──→ Артефакт 5 (URL-карта)
  │             │
  │             └──→ Артефакт 6 (Архитектура)
  │
  ├──→ Артефакт 3 (Диаграммы последовательностей)
  │
  ├──→ Артефакт 4 (Диаграмма состояний)
  │
  └──→ Артефакт 7 (Спецификация экранов)
         │
         └──→ Артефакт 5 (URL-карта)
                 │
                 └──→ Артефакт 6 (Архитектура)
```

**Принцип:** каждый артефакт ссылается на первоисточник (Артефакт 0) и на смежные артефакты через маппинги. Индекс-файл — точка входа, от которой расходятся пути к любому артефакту.
