## S4. Проведение и FIFO

### T30. Сервис проведения документа (atomic transaction)
**Приоритет:** P0 | **Роль:** BE | **Оценка:** 8 ч
**Артефакты:** Раздел 3.3, US-16, БП 6–7, TC-14 — TC-21
**Описание:** `post_document(doc_id)` в `documents/services.py`: атомарная транзакция с `SERIALIZABLE` изоляцией.
**Критерии приёмки:**
- [ ] `@transaction.atomic` + `SELECT ... FOR UPDATE` на TireCode
- [ ] Для каждой строки: проверка остатка (active codes на складе-источнике)
- [ ] Нехватка по любой строке → ROLLBACK + ошибка с указанием позиции и доступного количества
- [ ] FIFO: выбор по `created_at` ASC, `id` ASC (внутри дня)
- [ ] Пометка кодов: is_used=True, is_active=False, document=doc, used_at=now
- [ ] Уменьшение счётчиков (через модель или кэш)
