## 4. ГЛОССАРИЙ

| Термин | Определение |
|--------|-------------|
| DataMatrix-код | Двумерный матричный штрих-код, наносится на шины для маркировки |
| «Честный знак» | Система прослеживаемости товаров, внешняя служба для получения атрибутов кода |
| FIFO | First-In-First-Out — выбор кодов по дате загрузки в систему (внутри дня — по ID) |
| Площадка | Самостоятельная сущность (в MVP — одна: «Софийская Груз») |
| Склад | Принадлежит площадке; типы: основной (main) и ответственное хранение (oh) |
| Номенклатура | Уникальное сочетание brand + model + size; создаётся автоматически |
| Документ | Документ списания (СП) или выкупа (ВК) DataMatrix-кодов |
| Проведение | Атомарная транзакция: проверка остатка → FIFO-выбор → пометка кодов → счётчики |
| Распроведение | Откат: возврат кодов в активные, восстановление счётчиков |
| Списание с чужой площадки | Создание документа списания, где writeoff_platform ≠ source_platform |
| Выкуп | Перевязка кодов на склад автора документа, без перезапроса «Честного знака» |
| Manager | Начальник склада — полный доступ к документам своей площадки, чужие — только чтение |
| Storekeeper | Кладовщик — только свои документы; может списывать коды с любой площадки |

## 13. ГРАНИЦЫ ПРОЕКТА (MVP)

### В составе MVP
- Ручная загрузка файла с DataMatrix-кодами (текстовый формат, по коду на строку)
- Выбор склада перед загрузкой (ручная приписка кодов)
- Запрос данных в «Честный знак» через библиотеку `nechestniy_znak`
- Парсинг атрибутов шин: brand, model, size, product_name
- Авто-создание номенклатуры при первом сочетании brand + model + size
- Хранение кодов с дедупликацией по значению
- Логирование процесса загрузки + отчёт
- Управление пользователями: manager / storekeeper
- Документы списания и выкупа с полным жизненным циклом
- Экранное отображение кодов после проведения
- Счётчики активных кодов
- Фильтрация документов по площадкам
- Автосохранение черновика при разрыве соединения
- Карточка кода: текст + номенклатура + DataMatrix

### Вне состава (отложено)
- API-интеграция с 1С (автоматическая ежедневная загрузка)
- Печать кодов на А4
- Нешины (другие товарные категории)
- Реальный складской учёт остатков ТМЦ
- Вторая площадка «Софийская Легковой» (архитектура учитывает)
- Автоматический маппинг владелец → склад
