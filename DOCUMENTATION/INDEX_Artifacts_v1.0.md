## Глоссарий терминов

| Термин | Расшифровка |
|--------|-------------|
| DataMatrix | Двумерный матричный штрих-код, используемый в «Честном знаке» |
| Честный знак | Система обязательной маркировки товаров (ЦРПТ) |
| FIFO | First In, First Out — выбор кодов по дате загрузки (раньше загружен — раньше списан) |
| СП | Списание — документ типа `writeoff` |
| ВК | Выкуп — документ типа `buyout` |
| ОХ | Ответственное хранение — тип склада `oh` |
| Площадка | Самостоятельная логистическая единица (в MVP — «Софийская Груз») |
| Manager | Начальник склада — полные права на свою площадку, чтение чужих |
| Storekeeper | Кладовщик — только свои документы, списание с любой площадки |
