## Глоссарий

| Термин | Определение |
|--------|------------|
| DataMatrix-код | Двумерный матричный штрихкод, наносится на шину |
| «Честный знак» | Система цифровой маркировки и прослеживаемости товаров |
| Номенклатура | Уникальное сочетание brand + model + size |
| TireCode | Конкретный DataMatrix-код, привязанный к номенклатуре и складу |
| Платформа | Самостоятельная сущность (в MVP — одна: «Софийская Груз») |
| Склад | Единица учёта внутри площадки (Основной / Ответственное хранение) |
| Поставщик | Контрагент для складов ответственного хранения |
| FIFO | Выбор кодов по дате загрузки (внутри дня — по ID) |
| Списание | Документ списания кодов с площадки |
| Выкуп | Документ перевязки кодов на склад автора |
| Проведение | Атомарная транзакция: проверка → FIFO → пометка → счётчики → статус |
| Распроведение | Откат проведения: коды возвращаются в активные |
| Manager | Начальник склада — полный доступ к своей площадке, чтение чужих |
| Storekeeper | Кладовщик — только свои документы, списание с любой площадки |

## Сводка моделей данных

| Модель | Назначение | Ключевые поля |
|--------|------------|---------------|
| Platform | Площадка | name (unique) |
| Warehouse | Склад | name, warehouse_type, platform (FK), supplier (FK, nullable) |
| Supplier | Поставщик | name (unique) |
| TireNomenclature | Справочник номенклатуры | brand, model, size (unique_together), product_name (nullable) |
| TireCode | DataMatrix-код | qr_code (unique), nomenclature (FK), warehouse (FK), is_active, is_used, document (FK, nullable) |
| Document | Документ списания/выкупа | doc_type, number, status, author (FK), source_platform (FK), writeoff_platform (FK), source_warehouse (FK), target_warehouse (FK, nullable) |
| DocumentItem | Строка документа | document (FK), nomenclature (FK), quantity (unique_together: document + nomenclature) |
| User | Расширение стандартного User | platform (FK), role (manager / storekeeper) |

## Сводка состояний документа

| Состояние | Код | Кнопки | Что можно делать |
|-----------|-----|--------|------------------|
| Черновик | `draft` | Добавить строку, Сохранить, Отменить | Наполнение состава, номер не присвоен |
| Сохранён | `saved` | Добавить строку, Сохранить, Провести, Пометить на удаление | Редактирование, номер присвоен |
| Проведён | `posted` | Распровести, Экранное отображение | Только чтение, коды закреплены |

## Границы MVP

### В составе MVP
- Ручная загрузка файла с DataMatrix-кодами
- Выбор склада перед загрузкой
- Запрос в «Честный знак» + парсинг атрибутов
- Авто-создание номенклатуры
- Дедупликация по значению кода
- Логирование и отчёт о загрузке
- Управление пользователями (manager / storekeeper)
- Документы списания и выкупа
- Жизненный цикл: черновик → сохранён → проведён → распроведён / помечен на удаление
- Экранное отображение кодов после проведения
- Счётчики активных кодов
- Фильтрация документов по площадкам
- Автосохранение черновика
- Карточка кода с DataMatrix-изображением

### Вне состава (отложено)
- API-интеграция с 1С
- Печать кодов на А4
- Нешины (другие товарные категории)
- Реальный складской учёт остатков ТМЦ
- Вторая площадка «Софийская Легковой»
- Автоматический маппинг владелец → склад
