## Особенность чтения файлов

### Описание
При использовании read_file содержимое некоторых файлов может отображаться как экранированная строка вместо читаемого Django template.

### Причина
Метод read_file иногда возвращает содержимое с экранированными символами вместо оригинального текста.

### Решение
Использовать execute_command с cat для чтения оригинального содержимого файла.

### Правила работы с файлами
1. read_file: Может возвращать экранированные символы. Если содержимое нечитаемое, использовать cat через execute_command.
2. execute_command: Надёжный способ чтения оригинального содержимого файлов.
3. write_to_file: Предпочтительнее для перезаписи файлов.
4. edit_file: Использовать для точечных изменений.

### Логика
1. Считать файл через read_file
2. Если содержимое нечитаемое - использовать cat через execute_command
3. Внести изменения через edit_file или write_to_file
4. Проверить результат через cat

### Преимущества
- Надёжное чтение оригинального содержимого
- Избегание ошибок с экранированными символами
- Правильное применение изменений
