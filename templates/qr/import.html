Инструкция по импорту
  1. Подготовьте файл с QR-кодами (TXT или PDF)
  2. Каждый QR-код должен быть на отдельной строке
  3. Файл будет автоматически проверен в системе "Честный Знак"
  4. Успешно проверенные шины будут добавлены в базу данных
  5. Вы получите отчет об импорте
Пример формата TXT:
QR1234567890
QR0987654321
QR1122334455
...
